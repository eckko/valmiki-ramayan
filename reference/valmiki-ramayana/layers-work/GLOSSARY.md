# Glossary: fixed renderings for valmiki-ramayana layers

Read at the start of each chunk; extended by the reviewer, not the drafter.

- dharma = dharma (धर्म); karma = action (कर्म); ṛṣi / muni = sage (ऋषि / मुनि)
- rājan = O king (हे राजन्); tāta = dear one (तात)
- Names: plain transliteration (Rāma, Sītā, Lakṣmaṇa, Daśaratha, Vālmīki, Nārada); epithets stay epithets in the gloss
- Speaker lines "X uvāca": "X said:" / "X ने कहा:"
- Do not import the later story, other books or commentary
